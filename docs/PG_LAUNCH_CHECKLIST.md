# DALEUM PG 심사 및 자사몰 런칭 체크리스트

작성 기준일: 2026-07-08

## 1. 클라이언트에게 받아야 할 상품 일괄 등록 자료

관리자 > 상품 관리 > 일괄 등록에서 아래 정보를 엑셀 양식으로 받는다.

### 필수

- 상품명
- 판매가
- URL 슬러그 또는 자동 생성 가능한 상품명
- 판매 상태: PG 심사용 실제 판매 상품은 `active`, 준비 상품은 `draft`
- 대표 이미지 URL 1장 이상
- 초기 재고 또는 옵션별 재고
- 보관 방법: `room`, `chilled`, `frozen`
- 중량/구성 표시
- 원산지
- 상세 설명
- 식품 표시용 상품 스펙: 식품유형, 품목보고번호, 소비기한, 원재료명, 보관방법 등

### 권장

- 정가, 원가, SKU
- 카테고리 slug 또는 카테고리명
- 상세페이지 이미지 URL
- 브랜드 스토리
- 배지, 태그
- 영양 정보: 열량, 나트륨, 탄수화물, 당류, 지방, 단백질 등
- 알레르기 유발물질 및 혼입 가능성 문구
- 옵션: `옵션명:추가금:재고:SKU:판매여부`
- 노출 순서, 추천 상품 여부

### 이미지 기준

- 대표 이미지는 첫 URL이 대표 이미지로 저장된다.
- 상세페이지 이미지는 상품 설명 아래 이미지로 자동 노출된다.
- URL은 HTTPS 공개 접근이 가능해야 한다.
- Next 이미지 설정상 운영 전에는 Supabase Storage 또는 허용 도메인 이미지 사용을 권장한다.

## 2. 토스페이먼츠 PG 심사 준비

토스페이먼츠 공식 문서 기준 계약 흐름은 전자결제 신청, 서류 및 홈페이지 심사, 카드사 심사 순서다. 테스트 연동은 계약 전에도 가능하지만 심사 중 결제가 제한될 수 있다.

### 제출/준비 서류

- 개인사업자: 사업자등록증
- 법인사업자: 사업자등록증, 법인등기부등본, 주주명부, 법인인감증명서
- 대표자 또는 대리인 휴대폰 본인 인증 준비
- 정산계좌 정보
- 통신판매업 신고증 또는 신고번호
- 구매안전서비스 이용확인증이 필요한 경우 PG/은행 발급본
- 인감/사용인감/신분증/계좌사본은 PG사 또는 호스팅 신청 경로에 따라 추가 요청될 수 있음

### 홈페이지 심사 필수 상태

- 판매 가능한 실제 상품 1개 이상 등록
- 빈 카테고리 없음
- 상품 이미지 누락, 동일 이미지 반복, 깨진 이미지 없음
- 품절 상품, 샘플 상품만 있는 상태 금지
- 비회원도 구매 가능
- 푸터에 사업자등록증 기준 정보 기재
- 선택한 결제수단의 결제창이 테스트 키로 정상 노출
- 카드사 등록유의업종 해당 여부 사전 확인

## 3. 푸터 및 법정 고지

초기 화면 또는 푸터에서 소비자가 확인할 수 있어야 한다.

- 상호
- 대표자 성명
- 사업장 주소와 소비자 불만 처리 주소
- 전화번호
- 전자우편주소
- 사업자등록번호
- 통신판매업 신고번호
- 사업자정보 확인 링크
- 이용약관 링크
- 개인정보 처리방침 링크
- 배송/교환/반품/환불 정책 링크
- 호스팅 제공자

## 4. 식품 자사몰 표시사항

곤약 식품 판매이므로 상품 상세 또는 고시 정보에 아래 항목을 확보한다.

- 제품명
- 식품유형
- 내용량
- 원재료명
- 성분명 및 함량
- 영업소 명칭 및 소재지
- 제조연월일, 소비기한 또는 품질유지기한
- 품목보고번호
- 보관방법 또는 취급방법
- 용기/포장 재질
- 소비자 안전 주의사항
- 알레르기 유발물질
- 같은 제조시설 혼입 가능성 문구
- 영양성분
- 원산지
- 부정/불량식품 신고 안내
- 냉장/냉동 상품의 배송 및 보관 안내
- 품질보증 기준 및 소비자 상담 연락처

## 5. 약관/개인정보/운영 정책

- 회원 이용약관
- 비회원 주문 약관 또는 주문 조회 안내
- 개인정보 처리방침
- 개인정보 수집/이용 동의
- 마케팅 수신 동의 분리
- 개인정보 처리 위탁: PG, 배송사, 문자/메일, 호스팅, 데이터베이스
- 개인정보 보유기간: 회원, 주문, 결제, 배송, 상담, 로그
- 쿠키/분석 도구 안내
- 개인정보 보호책임자와 연락처
- 청약철회, 교환, 반품, 환불 정책
- 식품 특성상 반품 제한 사유
- 배송비, 도서산간 추가비, 무료배송 기준
- CS 운영시간

## 6. 런칭 전 기술 점검

### 결제

- 토스 테스트 키로 결제창 호출
- 주문 생성 금액과 토스 승인 금액 일치 검증
- 결제 성공 후 `orders`, `payments`, `order_items`, 재고 차감 확인
- 결제 실패/이탈 주문 처리 확인
- 웹훅 URL 등록 및 재처리 멱등성 확인
- 취소/환불 API 확인
- 운영 키 반영 후 소액 실결제 및 즉시 환불 테스트

### 계정/보안

- 관리자 계정 role 확인
- 관리자 라우트 접근 제어 확인
- Supabase RLS 확인
- Service role key 서버 전용 확인
- 운영 환경변수 점검
- 도메인, SSL, 리다이렉트 확인
- 이미지 도메인 허용 설정 확인

### 상품/주문

- 실제 판매 상품 active 전환
- 가격, 정가, 재고, 옵션 재고 확인
- 대표 이미지와 상세 이미지 로딩 확인
- 장바구니, 체크아웃, 비회원 구매 확인
- 회원가입, 로그인, 마이페이지 주문 조회 확인
- 배송비 정책 확인
- 주문 상태 변경 및 송장 등록 확인

### 콘텐츠

- 메인 배너/팝업/공지 최종 반영
- About, Support, FAQ 확인
- 푸터 사업자 정보 최종 반영
- SEO 메타, OG 이미지 확인
- 개인정보 처리방침/약관 링크 확인

## 7. 클라이언트 요청 자료 패키지

- 사업자등록증
- 법인등기부등본, 주주명부, 법인인감증명서
- 통신판매업 신고증
- 정산계좌 정보
- 사업장 주소, 반품 주소, CS 전화, 이메일, 운영시간
- 대표자명, 개인정보 보호책임자명
- 택배사, 계약 운임, 도서산간 정책
- 배송 출고 마감 시간
- 교환/반품/환불 기준
- 모든 상품 엑셀 양식
- 상품 대표 이미지와 상세 이미지
- 패키지 라벨 이미지
- 식품 표시사항 원본
- 영양성분 자료
- 알레르기/혼입 가능성 문구
- 인증서: HACCP, FSSC 22000, VEGAN, HALAL 등
- 품목제조보고번호
- 원산지 증빙
- 브랜드 로고, 배너 이미지, 팝업 이미지
- 이용약관, 개인정보 처리방침, 배송/환불 정책 초안 승인
